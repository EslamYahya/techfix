# 11 — القرارات والأسئلة المفتوحة

## قرارات متخذة (مصدرها Release v1 أو اتساق النموذج)
Modular Monolith؛ NestJS+Prisma+PostgreSQL/PostGIS؛ Redis/BullMQ؛ REST `/api/v1`؛ ثلاثة أدوار فقط؛ `hasShop` علامة؛ آلة الحالات أعلاه؛ المقبول غير قابل للتعديل والعرض الإضافي مرتبط؛ الإنجاز بتأكيد العميل؛ نقدًا=حجز فوري، إلكترونيًا=webhook؛ الإنجاز ≠ الدفع؛ الأهلية ثم الترتيب؛ العنوان مخفي حتى الحجز؛ التدقيق منذ اليوم الأول؛ المتجر/المحفظة/التتبع الحي/الدردشة لاحقًا.

## قرارات اتخذتها هنا (راجعها)
1. **التقييم يتطلب السداد الكامل** (كما في النموذج) — مفتاح `requirePaid` في `canRate`. بديل: التقييم عند COMPLETED فقط.
2. **الإلغاء المجاني حتى CONFIRMED**؛ بعدها عبر الإدارة/النزاع (يطابق النموذج).
3. **لا تعديل مباشر للأوزان بلا تدقيق ولا مجموع≠100.**
4. **الإدارة لا تقبل عرضًا ولا تنفّذ مهمة نيابةً** (تخالف ✅ في الجدول الأصلي).
5. **غير المالك يرى 404.**
6. **العمولة من جهة المهندس** وتُثبَّت عند الإكمال.

## مفتوحة (لا نخترع سياسة)
| السؤال | يؤثر على |
|---|---|
| نسبة العمولة (10٪ توضيحية) وهل تختلف بالخدمة/المهندس | الأرباح، `platform_settings` |
| مزوّد الدفع الإلكتروني ورسومه ودعم محافظ مصر | `PaymentProvider` |
| مهلة رد المهندس، صلاحية العرض، مدة خمول الطلب | المهام الدورية |
| سياسة الإلغاء بعد الانطلاق: رسوم؟ من يتحمل؟ مراجعة الإدارة | `FREELY_CANCELLABLE`، النزاعات |
| سياسة الاسترداد والنزاع (من يقرر، مهل) | الماليات |
| وثائق التوثيق المطلوبة ومدة المراجعة وإعادة التقديم | `engineer_documents` |
| الكتالوج النهائي للخدمات والفروع الفرعية والتسعير الاسترشادي | `services` |
| عدم الحضور: رسوم/عقوبات/عدّاد | النزاعات |
| سياسة منع التحايل (التواصل خارج المنصة) | الخصوصية |
| احتفاظ بالبيانات وحذف الحساب والامتثال لقانون حماية البيانات المصري | كل الجداول |
| إضافة «معدل الاستجابة» و«عدد المهام» لصيغة الترتيب | `matching` |
| OTP هاتفي إلزامي عند التسجيل؟ مزود SMS | auth |
| نطاق جغرافي مدعوم (القاهرة الكبرى فقط؟) والتحقق من الإحداثيات | `location` |
| لغات الإشعار والمنطقة الزمنية للجدولة | notifications |
