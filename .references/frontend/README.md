# TechFix — مرجع الواجهة الأمامية (Release v1)

نموذج تفاعلي مترابط + وثائق، مبني على `docs/source/IDEA.md` و`TechFix-Release-v1.md`. هو المرجع الأساسي لبناء الواجهة الفعلية.

## التشغيل
افتح `prototype/index.html` مباشرة في Chrome، أو شغّل `python3 -m http.server` داخل `prototype/`. حسابات التجربة (كلمة المرور `demo1234`): `tarek@demo.techfix` عميل · `ahmed@demo.techfix` مهندس · `admin@demo.techfix` مشرف. شريط «عرض تجريبي» أسفل الشاشة يبدّل الدور ويعيد ضبط البيانات.

**جرّب القصة كاملة**: عميل ← طلب جديد ← اختيار مهندس ← (مهندس) قبول وعرض سعر ← (عميل) موافقة ودفع ← (مهندس) انطلاق وتنفيذ وعرض إضافي ← إنهاء ← (عميل) تأكيد وتقييم ← (مهندس) تأكيد استلام النقد ← (مشرف) متابعة.

## المحتويات
- `prototype/` — النموذج: 4 صفحات عامة + 9 عميل + 6 مهندس + 5 مشرف، نظام تصميم واحد، ومحاكاة لآلة الحالات والصلاحيات والترشيح.
- `docs/01-product-logic.md` — المنطق والقواعد.
- `docs/02-page-map-and-linking.md` — الصفحات والمسارات وكيف تنتقل.
- `docs/03-status-labels.md` — قاموس النصوص (لا مصطلحات برمجية في الواجهة).
- `docs/04-design-system.md` — الهوية والمكوّنات.
- `docs/05-frontend-structure.md` — هيكل React ومطابقة ملفات النموذج.
- `docs/06-decisions-and-open-questions.md` — ما تغيّر وما بقي مفتوحًا.
- `docs/source/` — وثيقتا المشروع الأصليتان.

> `prototype/guide.html` هي الصفحة الوحيدة التي تعرض الأسماء الداخلية للحالات، لأنها موجّهة للمطوّرين.
