# نظام التصميم الموحّد

ملف واحد: `prototype/css/techfix.css`. كل البوابات الأربع (عام، عميل، مهندس، مشرف) تستخدمه بلا استثناءات.

## الهوية
مستمدة من الشعار: أزرق مخضرّ للحلقة والأخضر المائي، مع برتقالي «سلامة ميدانية» **للإجراء الرئيسي والحالة الجارية فقط**.

| رمز | فاتح | الاستخدام |
|---|---|---|
| `--ink` | #0C3547 | النص والقائمة الجانبية |
| `--brand` | #1D6A91 | الروابط والأزرار الثانوية |
| `--teal` | #2A9A98 | التقدّم والتحديد |
| `--accent` | #F26B1D | الإجراء الرئيسي والحالة الجارية |
| `--paper / --surface` | #F3F7F8 / #FFF | الخلفية والبطاقات |
| ok / warn / bad | #168A5B / #9A6500 / #C03636 | حالات النجاح والانتظار والخطأ |
الثيم الداكن عبر `data-theme="dark"` على `<html>` بنفس الأسماء.

## الخط والاتجاه
Cairo (400/600/700/800) مستضاف محليًا. RTL أولًا، وخصائص منطقية فقط (`inline-start/end`)، والأرقام لاتينية (2,200). أيقونات Lucide بخط رفيع موحّد (`ic('name')`).

## المكوّنات المميزة
- **مسار الخدمة** (`.rail`، و`.seg` المصغّر): الشكل الرئيسي لحالة الطلب في كل الأدوار.
- **التذكرة** (`.ticket`): بطاقة بقصّة مثقوبة للطلب وعرض السعر والفاتورة.
- بطاقات مسطّحة بحدود رفيعة وزوايا صغيرة، ولا ظلال إلا للتذكرة والنوافذ.
- أزرار: `--primary` (برتقالي، واحد بارز في الشاشة)، `--solid`، `--ghost`، `--danger`.
- نماذج: `.field` + `.input` + رسالة `.err`؛ تحقق عند الإرسال برسائل عربية.
- جداول `.table` مع التفاف أفقي، وبنود السعر بلا عمود تقني.
- `.empty` للحالات الفارغة، `.note` للتنبيهات، `.toast` للنتائج، `.sheet` للنوافذ.

## التخطيط
- الجوّال: شريط تبويب سفلي (5 عناصر) + رأس علوي.
- ≥960px: قائمة جانبية داكنة 268px + محتوى؛ العميل والمهندس حتى 900px، المشرف عريض.
- الموقع العام: شريط علوي + أقسام بعرض 1160px.

## الوصولية
تركيز مرئي على كل العناصر، أهداف لمس ≥ 44px، `aria-label` للأزرار الأيقونية، `aria-current` للتنقل، احترام `prefers-reduced-motion`، الحالة لا تعتمد على اللون وحده (نص + شارة).
